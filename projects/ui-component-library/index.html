Multi-Framework UI Component Library

Morgan Stanley · Production work

Core React and Angular component library used across 600+ internal applications.

  • React 18
  • Angular 17
  • TypeScript
  • Storybook
  • Vite

Context

Internal dashboards and data-visualization applications use both React and Angular. This core component library supports both frameworks across 600+ internal applications.

My contribution

Architected and developed the multi-framework library using React 18, Angular 17, and TypeScript, primarily for dashboarding and data visualization. Built the Angular 14 layer earlier in my tenure and owned API design, releases, versioning, and migration support across modules as the platform developed.

Reach

The library is used across 600+ internal applications, extending the impact of the component work across multiple application teams. The library is part of a monorepo containing over one million lines of code.

My related developer-tooling work includes features and bug fixes for the Nx Vite builder.
